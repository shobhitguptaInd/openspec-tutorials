# OpenSpec Sample Projects

Welcome to the OpenSpec sample projects repository! This collection contains complete, working examples demonstrating how to use OpenSpec for specification-driven development across multiple programming languages and platforms.

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/shobhitguptaInd/openspec-tutorials.git
cd openspec-tutorials

# Browse to any sample project
cd cobol-jcl/hello-openspec-cobol
```

## 📦 What's Included in Each Sample

Every sample project includes:

- **📝 Complete OpenSpec Specifications**: Full `proposal.md` files with problem statements, solutions, and requirements
- **💻 Working Source Code**: Production-ready code that implements the specifications
- **📖 Step-by-Step Tutorial**: Detailed README with setup instructions and explanations
- **✅ Tests & Validation**: Unit and integration tests demonstrating best practices
- **🎯 Exercise Files**: Practice exercises with solutions to reinforce learning
- **🎥 Video Walkthrough**: Optional video tutorial explaining the implementation (where available)

## 🛠️ Prerequisites

Different samples have different requirements. Check each project's README for specific prerequisites.

### General Requirements
- [OpenSpec CLI](https://github.com/shobhitguptaInd/OpenSpec) installed
- Git for version control
- Basic understanding of the target programming language

### Language-Specific Requirements
- **COBOL/JCL**: GnuCOBOL or IBM COBOL compiler
- **Java**: JDK 17+, Maven or Gradle
- **.NET**: .NET 8 SDK
- **Multi-Language**: Requirements from respective languages

## 📖 How to Use These Samples

1. **Choose a Sample**: Browse the categories above and pick a project that matches your skill level
2. **Clone the Repository**: Use the quick start command above
3. **Navigate to the Project**: `cd` into the specific sample directory
4. **Read the README**: Each project has detailed setup and usage instructions
5. **Explore the Specs**: Review the OpenSpec `proposal.md` to understand the requirements
6. **Run the Code**: Follow the setup instructions to run the working implementation
7. **Try the Exercises**: Complete the practice exercises to reinforce your learning
