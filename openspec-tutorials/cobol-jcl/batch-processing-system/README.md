# Batch Processing System (COBOL/JCL)

A complete batch processing system demonstrating COBOL programs with JCL job control and error handling.

## 🎯 Overview

This intermediate-level sample shows how to build a production-ready batch processing system that:
- Processes large data files in batches
- Uses JCL for job control and scheduling
- Implements comprehensive error handling
- Generates processing reports
- Follows mainframe best practices

## 📋 Prerequisites

- GnuCOBOL 3.x or IBM COBOL compiler
- JCL interpreter or mainframe access
- Understanding of COBOL file processing
- Familiarity with batch processing concepts

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/shobhitguptaInd/openspec-tutorials.git
cd openspec-tutorials/cobol-jcl/batch-processing-system

# Compile the programs
cobc -x -o batch-processor src/BATCHPROC.cbl

# Run the batch job
./batch-processor
```
